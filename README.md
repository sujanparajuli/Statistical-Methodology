# Statistical Methodology Coursework

A structured portfolio of statistical methods and applied analyses completed at **Norwich University** during **Spring 2026**.

This repository documents my experience selecting statistical methods, checking assumptions, interpreting results, and communicating conclusions. The work is presented as coursework and will be expanded with original assignment files, code, tables, and figures.

## Coursework portfolio

| Area | Methods and applications |
| --- | --- |
| [Hypothesis testing](coursework/01-hypothesis-testing/README.md) | One- and two-sample *t*-tests, confidence intervals, significance, and interpretation |
| [Chi-square methods](coursework/02-chi-square/README.md) | Categorical-data analysis, expected counts, and tests of association |
| [Two-way ANOVA](coursework/03-two-way-anova/README.md) | Main effects, interaction effects, assumptions, and interpretation |
| [Regression](coursework/04-regression/README.md) | Old Faithful analysis and state life-expectancy modeling |

## Skills demonstrated

- Translating questions into testable statistical hypotheses
- Choosing methods appropriate to variable type and study design
- Checking assumptions before interpreting a model or test
- Distinguishing statistical significance from practical meaning
- Interpreting confidence intervals, *p*-values, effects, and residuals
- Communicating limitations and avoiding causal claims from observational data
