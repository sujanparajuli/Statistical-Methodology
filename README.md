# Statistical Methodology Coursework

Applied statistics coursework completed at **Norwich University** in **Spring 2026**. This repository preserves my Python lab work and the datasets used in class while presenting the material by statistical method instead of assignment number.

## Coursework at a glance

| Topic | Work represented |
| --- | --- |
| [Hypothesis testing](coursework/01-hypothesis-testing/) | Welch and paired *t*-tests, confidence-based reasoning, boxplots, and Q–Q plots |
| [One-way ANOVA](coursework/02-one-way-anova/) | Cholesterol treatment and methylphenidate dosage comparisons |
| [Two-way ANOVA](coursework/03-two-way-anova/) | Birthweight, heart rate, blood pressure, exercise, main effects, and interactions |
| [Nonparametric methods](coursework/04-nonparametric-methods/) | Mann–Whitney and Kruskal–Wallis analyses |
| [Linear regression](coursework/05-linear-regression/) | Old Faithful, Anscombe’s quartet, birthweight, blood pressure, and state life expectancy |
| [Logistic regression](coursework/06-logistic-regression/) | O-ring failure and low-birthweight classification |

## Skills demonstrated

- Exploratory plots and descriptive statistics
- Hypothesis formulation and test selection
- Assumption checks and residual diagnostics
- One- and two-factor ANOVA
- Parametric and nonparametric inference
- Simple, multiple, and logistic regression
- Interpretation of coefficients, *p*-values, confidence intervals, odds ratios, and model limitations
- Python with pandas, NumPy, SciPy, statsmodels, seaborn, and Matplotlib

## Run the work

Each topic folder keeps its scripts beside the required datasets so the original relative file paths continue to work.

```bash
python -m venv .venv
pip install -r requirements.txt
python coursework/05-linear-regression/old_faithful_regression.py
```
