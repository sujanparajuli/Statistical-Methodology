# Regression Analysis

## Applied coursework

### Old Faithful

Used the Old Faithful dataset as a setting for studying association and regression between quantitative variables.

### State life expectancy

Explored state-level life expectancy with regression methods and considered how multiple explanatory variables relate to an outcome.

## Topics practiced

- Creating and interpreting scatterplots
- Fitting simple and multiple linear regression models
- Interpreting slopes, fitted values, and model fit
- Examining residuals and regression assumptions
- Recognizing omitted-variable, observational-data, and causal limitations
